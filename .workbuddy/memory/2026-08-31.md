## 🔍 SEO 结构诊断（同日，老板问"是不是网站结构不利于收录"）
**根因1（最致命）：首页是「断头路」**
- 首页静态 HTML 只有 1 个自链接(/)，没有任何指向分类页/产品页的静态链接
- 产品靠 JS 渲染：`window.__PRODUCTS__` 内嵌 JSON + fetch(`/products-public.json`)，链接是 `'/product/'+sk` 动态拼接
- Google 爬虫只见静态 HTML → 首页给不了 996 产品页任何内链权重
- 反观**分类页正常**：ramadan/ 有 964 个静态产品链接
- 完美解释工作记忆里「884 个 Discovered-not-indexed(知道了却没收录)」

**根因2（内容层，雪上加霜）：重复/薄内容**
- 986 个有描述产品，仅 526 唯一描述；135 组重复覆盖 460 产品（近一半）
- 101 组重复标题覆盖 394 产品；10 个完全无描述
- Google 判「thin/duplicate content」，进一步压收录

**已排除（不是问题）：on-page SEO 达标** — title/desc/canonical/robots/h1/sitemap 均正确，robots.txt 干净

**修复方向**：首页静态化（把内嵌产品数据渲染成真 `<a href>` 链接到分类页+顶部分类导航）、去重描述/标题

- **结论: 每个产品页都被分类页链接到了(内链完整), 但首页是"断头路"不分发权重给任何分类/产品**

**外部权威资料共识(2026/08/31 搜索):**
- "Discovered-not-indexed" = Google 知道 URL 但未爬 = **弱内链/优先级低**（InstantIndexer）
- "Crawled-not-indexed" = Google 爬了但拒收 = **内容质量+内链问题, 不是 Cloudflare**（LinkedIn Agha Ali）
- **JS 渲染(CSR)的两波索引**: 首波抓原文 HTML, 二波才渲染 JS; CSR 内容/链接依赖二波渲染, 慢几天~几周, AI 爬虫(GPTBot等)完全不跑 JS（Lynx/SEOtop/overthetop）
- **唯一完美对标案例**: dev.to/alex_liao 172页静态站+Cloudflare Pages 同样 3个月 收录难, 最终靠: JSON-LD结构化数据+真实href内链+去模板化内容+外部链接 解决

**最终判断(老板拍板依据):**
1. **首页断头路 = 真问题**(首波抓取无链接) → 值得改, 改动面小可回滚, 0收录页改了不会降权
2. **薄内容(描述平均29字符) = 真问题** → 但要慎重, 是"补内容"不是"删改已验证页"
3. NOT 需要重构: Cloudflare Pages免费静态+JSON架构本身OK(SEOTop: SSG类最优),  首页JSON化是细节非命门
4. 已收录217页(尤其产品页)结构其实不差: 有canonical/JSON-LD/内链——**不会因其他改动降权**
