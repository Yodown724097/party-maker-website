## 二、关键数据与发现

### 1. PM Performance（SC 近 3 月 6/9–9/8）
- 总展现 2392 / 点击 21 / CTR 0.88% / 平均排名 21.96
- 月度展现 430→711→849 向上；P0 首页静态化(8-31 上线)已见效
- 品牌词占点击 67%（获客弱）；首页占全站展现 83%
- 移动端排名 9.61 远优于桌面 25.16
- 博客内容页排名(8-10)优于产品页 → 内容页是获客突破口
- 美/英/澳英语市场有展现 0 点击 → 英文 snippet 吸引力短板

### 2. PP vs PM 对比（扒原文 HTML 结构）
- **PP = 单页站**：/products /blog /about 等所有 URL 均返回同一份首页 HTML；导航是 #home/#about 页内锚点；无 sitemap(Cloudflare fallback)、无 canonical、无 JSON-LD、内链仅锚点
- **PP 月访问 370（美国 120）** → 单页集权 + 老域名(Since 2009) + 外链吃红利
- PM 技术更规范（sitemap 937 / canonical / JSON-LD / 41 内链 / P0P2 优化）；短板是薄内容（产品描述平均 29 字符）+ 新域名权重低
- **结论：PP 不比 PM 技术先进，"感觉更好"来自老域名+单页集权+好文案，非架构**

### 3. Cloudflare Pages 免费版限制（2026 多源核实）
- 带宽/静态请求 **无限**；构建 500/月（1 并发，20min 超时）；**部署文件 20000 上限**；单文件 25 MiB
- 几千产品页（~6000 文件）**不超许可**；真实代价 = git 仓库体积涨 + 构建时间线性涨（仍 <20min）

## 四、B2B 产品页模板方案（版式图已在今日会话 inline 展示，待定稿实施）
