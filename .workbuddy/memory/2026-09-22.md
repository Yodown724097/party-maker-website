## 🔴 权限踩坑（教训已进技能）

**Redirect Rules 需要的权限名是 `Zone → Dynamic Redirect → Edit`**
- ❌ 我先猜成 `Zone → Config → Rules → Edit` → **错，害老板来回试三轮**
- ⚠️ 且**界面中文叫「单一重定向」**，API 权限名却叫 Dynamic Redirect —— **同一功能两个名字，CF 自己没统一**
- **铁律：CF 权限名有几十个且 Write/Edit 混用，唯一可靠办法是查对应 API 的官方文档**
  （文档页会写「Required API token permissions: at least one of the following…」）
