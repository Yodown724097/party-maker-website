### 🔴 未修但已查实的两个真 bug（留待大改时处理，别忘）
1. **CRLF 导致全量重建**：`cart_js_version()` 用 `read_bytes()` 算 md5，Windows 检出是 CRLF、
   Linux 是 LF → 同一份 cart.js 在两机算出不同版本号（Win `ef8cad7816c3` / Linux `9393c1d99d57`），
   且与 `.build_cache.json` 对不上 → **Windows 上每次构建都全量重建 996 页**。
   修法：算哈希前 `raw.replace(b"\r\n", b"\n")`。已验证修复后缓存命中率 0% → 100%。
2. **保护名单变化不触发重建**：名单不在 `HASH_FIELDS` 里，改了名单缓存判定无变化 →
   页面不重建 → **线上 title 不变，白改一场**。修法：把「该页是否受保护」并入 `compute_product_hash`。

### ✅ 已确认安全的设计（大改时别破坏）
